# Calculadoras de liberdade financeira

Site estático para GitHub Pages. Preserve a estrutura para manter os links atuais:

- `Jorge/index.html`
- `Luiz/index.html`
- `index.html` (página inicial)

A página pública mostra somente um patrimônio de referência, calculado como renda mensal desejada × 12 ÷ taxa de retirada anual de 4%. Em seguida, destaca a chamada para conversar com o assessor pelo WhatsApp. A análise detalhada de aporte, retorno real e trajetória fica com o assessor.

O visitante preenche idade, idade desejada, renda mensal, patrimônio investido, investimentos e contato. O botão abre o WhatsApp com a mensagem pronta; a pessoa precisa revisar e enviar.

## Atualização

## Privacidade

Como o repositório público é acessível a todos, o HTML/JavaScript pode ser inspecionado. O número de destino do WhatsApp faz parte do link. Não inclua senhas, dados de acesso ou dados confidenciais de clientes no código.

## Premissa

O patrimônio exibido é uma referência simplificada por taxa de retirada de 4% ao ano, não uma garantia de renda sustentável. Não considera impostos, taxas, volatilidade, risco de sequência de retornos ou mudanças futuras.
